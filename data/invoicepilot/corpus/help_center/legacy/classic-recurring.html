Repeating invoices (Classic)

Last updated: 2024-09-12

Applies to: InvoicePilot 1.9.0

Classic has no automatic recurring invoices. Use Duplicate to copy last month's invoice.

Some users set a calendar reminder to duplicate invoices each month.
