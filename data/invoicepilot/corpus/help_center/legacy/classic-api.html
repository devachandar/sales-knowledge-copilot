Classic API

Last updated: 2025-01-20

Applies to: InvoicePilot 1.9.0

Classic integrations use API v1 at /v1 with page-based pagination: ?page=2&per_page=50.

Errors are plain text messages with no error codes. Rate limit: 30 requests per minute on every plan.
