Error subcodes

Last updated: 2026-07-01

Applies to: InvoicePilot 2.2.1+

Available on: Starter, Professional, Enterprise

Some errors have a more specific subcode. The HTTP status is the same as the main code on Error codes.

HTTPCodeMeaningRetry?
404IP-4041The resource exists but belongs to another organizationNo
409IP-4091A request with this Idempotency-Key is still being processedYes, after 1 second
422IP-4221Line item validation failed (quantity, rate, or tax)No
422IP-4222The currency is not enabled for this organizationNo
422IP-4223The customer is archivedNo
422IP-4224The invoice is void and cannot be changedNo
422IP-4225The estimate is not accepted, so it cannot be convertedNo
422IP-4226Webhook URL must use HTTPSNo
429IP-4291Too many concurrent requests (more than 10 in flight per key)Yes, after Retry-After
503IP-5031Payment processor unavailableYes, with backoff
Note: Older integrations that only check the main code keep working: IP-4221 to IP-4226 are all HTTP 422 validation errors.
