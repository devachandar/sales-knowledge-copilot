Node.js SDK

Last updated: 2026-08-03

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Install with npm install @invoicepilot/node. The current version is 2.4.1 and it supports Node 18 and later.

import InvoicePilot from '@invoicepilot/node';

const ip = new InvoicePilot({ apiKey: process.env.IP_KEY, maxRetries: 2 });
const inv = await ip.invoices.create({ customerId: 'cus_8812', currency: 'EUR', lineItems: [...] },
                                     { idempotencyKey: '7f9c2e1a' });
await ip.invoices.send(inv.id);

Method names match the Python SDK in camelCase: ip.invoices.void(), ip.payments.delete(), ip.customers.getStatement(), ip.webhooks.verifySignature().

Like the Python SDK, it retries 429, 500, and 503 errors automatically up to maxRetries (default 2).
