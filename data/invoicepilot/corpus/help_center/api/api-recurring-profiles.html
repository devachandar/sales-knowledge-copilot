Recurring profiles endpoint

Last updated: 2026-05-11

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Added to API v2 on 2026-05-11. See the API changelog.

MethodPathDoes
GET/v2/recurring_profilesList recurring profiles
POST/v2/recurring_profilesCreate a recurring profile
POST/v2/recurring_profiles/{profile_id}/pausePause a profile. No invoices are generated while paused
POST/v2/recurring_profiles/{profile_id}/resumeResume a profile from the next scheduled date

next_run_at is returned in UTC. Since 2.3.1 schedules are calculated in UTC.
