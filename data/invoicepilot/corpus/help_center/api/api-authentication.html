Authentication

Last updated: 2026-01-20

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Create an API key under Settings > Developer > API Keys. Send it as a bearer token.

curl https://api.invoicepilot.example/v2/invoices \
  -H "Authorization: Bearer ip_live_xxxxxxxxxxxx"

Keys start with ip_live_ for production and ip_test_ for the sandbox. Keys can be scoped to read-only.
