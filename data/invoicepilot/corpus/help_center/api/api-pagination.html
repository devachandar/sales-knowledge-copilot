Pagination (v2)

Last updated: 2026-01-20

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

List endpoints in v2 return up to 100 items and a next_cursor. Pass it back as ?cursor= to get the next page. When next_cursor is null you have reached the end.

GET /v2/invoices?limit=100
{
  "data": [...],
  "next_cursor": "eyJpZCI6IjEyMzQ1In0"
}
