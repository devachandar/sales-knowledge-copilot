Bank transactions endpoint

Last updated: 2026-06-15

Applies to: InvoicePilot 2.3.0+

Available on: Starter, Professional, Enterprise

Added to API v2 on 2026-06-15. See the API changelog.

MethodPathDoes
GET/v2/bank_accountsList connected bank accounts
GET/v2/bank_transactionsList transactions. Filters: bank_account_id, status=unmatched|matched
POST/v2/bank_transactions/{transaction_id}/matchMatch a transaction to an invoice or expense
POST/v2/bank_transactions/{transaction_id}/unmatchUndo a match (within 30 days)
Note: Matching through the API follows the same rules as the app. On 2.3.1, foreign-currency transactions are not converted before auto-match compares amounts (BUG-2310-01), so match them explicitly.
