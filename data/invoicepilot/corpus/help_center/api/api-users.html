Users endpoint

Last updated: 2026-07-01

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Added to API v2 on 2026-07-01. See the API changelog.

MethodPathDoes
GET/v2/usersList users and their roles
POST/v2/users/inviteInvite a user. The invite link expires after 7 days
PATCH/v2/users/{user_id}Change a user's role
DELETE/v2/users/{user_id}Remove a user and free the seat

Assigning a custom role through the API needs Enterprise. On other plans, use Admin, Accountant, Staff, or Read-only.
