Reports endpoint

Last updated: 2026-05-11

Applies to: InvoicePilot 2.3.0+

Available on: Starter, Professional, Enterprise

Added to API v2 on 2026-05-11. See the API changelog.

MethodPathDoes
GET/v2/reportsList saved custom reports
POST/v2/reports/{report_id}/runRun a saved report. Params: date_from, date_to, format=csv|xlsx|json
GET/v2/report_runs/{run_id}Check a run and get its download link

Report runs are asynchronous. Poll /v2/report_runs/{run_id} until status is complete.

Known issue: BUG-2300-01 also affects the API: runs spanning more than 3 years fail. Split the range.
