API quickstart

Last updated: 2025-07-14

Applies to: InvoicePilot 2.0.0+

Available on: Starter, Professional, Enterprise

The InvoicePilot API is the recommended way to integrate with InvoicePilot. All endpoints live under https://api.invoicepilot.example/v1.

curl https://api.invoicepilot.example/v1/invoices?page=1&per_page=50 \
  -H "Authorization: Bearer YOUR_API_KEY"

Use page and per_page to page through results. The maximum per_page is 200.
