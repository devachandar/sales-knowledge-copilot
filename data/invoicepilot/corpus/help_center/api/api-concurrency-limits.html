Concurrency limits

Last updated: 2026-07-01

Applies to: InvoicePilot 2.2.1+

Available on: Starter, Professional, Enterprise

Besides the per-minute rate limit, each API key can have at most 10 requests in flight at once.

An 11th parallel request gets HTTP 429 with IP-4291 and a Retry-After header. This is different from IP-4290, which means the per-minute limit was reached.

The concurrency limit is the same on every plan. Per-minute limits are 60, 300, or 1,000 by plan.
