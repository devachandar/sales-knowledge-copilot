Rate limits

Last updated: 2026-05-11

Applies to: InvoicePilot 2.3.0+

Available on: Starter, Professional, Enterprise

Rate limits are per organization, counted per minute.

PlanRequests per minute
Starter60
Professional300
Enterprise1,000

Headers

Every v2 response includes:

  • X-RateLimit-Limit: your limit per minute
  • X-RateLimit-Remaining: requests left in this window
  • X-RateLimit-Reset: Unix time when the window resets

When you go over, you get HTTP 429 with error code IP-4290 and a Retry-After header in seconds.

Note: in 2.2.0 these headers were missing (BUG-2200-02). Fixed in 2.3.0.

Need more?

Higher limits come with a higher plan. Enterprise customers can ask their CSM about a custom limit.
