Expenses endpoint

Last updated: 2026-04-02

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Added to API v2 on 2026-04-02. See the API changelog.

MethodPathDoes
GET/v2/expensesList expenses. Filters: category_id, date_from, date_to
POST/v2/expensesRecord an expense
POST/v2/expenses/{expense_id}/receiptUpload a receipt image (JPEG, PNG, or PDF, up to 10 MB)
DELETE/v2/expenses/{expense_id}Delete an expense

Receipts uploaded through the API are scanned the same way as receipts uploaded in the app.
