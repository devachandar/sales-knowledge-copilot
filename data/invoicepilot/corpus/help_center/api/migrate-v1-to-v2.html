Migrate from API v1 to v2

Last updated: 2026-02-15

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Changev1v2
Base path/v1/v2
Pagination?page=2&per_page=50?cursor=...&limit=100
ErrorsPlain text messageJSON with IP- error codes
Rate limit headersNoneX-RateLimit-* (from 2.3.0)
IdempotencyNot supportedIdempotency-Key header
  1. Create a new v2 key or reuse your v1 key; both work.
  2. Switch list calls to cursor pagination.
  3. Update error handling to read error.code.
  4. Add Idempotency-Key to POST calls so retries are safe.

There is no shutoff date for v1 yet. We will give at least 12 months' notice.
