Error codes

Last updated: 2026-05-11

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Errors return JSON with an HTTP status, a code, and a message.

{
  "error": {
    "code": "IP-4220",
    "message": "line_items[3].quantity must be greater than 0"
  }
}
HTTPCodeMeaningRetry?
400IP-4000Malformed request or invalid JSONNo
401IP-4010Missing or invalid API keyNo
403IP-4030Key lacks permission, or the limit for your plan is reachedNo
404IP-4040Resource not foundNo
409IP-4090Idempotency-Key was reused with a different request bodyNo
422IP-4220Validation failed; see messageNo
429IP-4290Rate limit exceeded; wait for Retry-AfterYes
500IP-5000Internal errorYes, with backoff
503IP-5030Bank feed provider unavailableYes, with backoff

Idempotency

Send an Idempotency-Key header on POST requests. Retrying with the same key returns the original result instead of creating a duplicate. Keys are kept for 24 hours.
