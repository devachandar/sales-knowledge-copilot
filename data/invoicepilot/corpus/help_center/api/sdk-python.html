Python SDK

Last updated: 2026-08-03

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Install with pip install invoicepilot. The current version is 3.2.0 and it supports Python 3.9 and later.

from invoicepilot import Client

client = Client(api_key="ip_live_xxxx", max_retries=2)
inv = client.invoices.create(customer_id="cus_8812", currency="EUR",
                             line_items=[{"description": "Consulting", "quantity": 10, "rate": 150}],
                             idempotency_key="7f9c2e1a")
client.invoices.send(inv.id)
MethodAPI call

client.webhooks.verify_signature(payload, signature, timestamp, secret)Checks X-InvoicePilot-Signature locally

Retries

The SDK retries IP-4290, IP-4291, IP-5000, and IP-5030 automatically with backoff, up to max_retries times (default 2). It never retries 4xx validation errors.

List methods such as client.invoices.list() follow next_cursor for you. Use auto_paginate=False to get one page.
