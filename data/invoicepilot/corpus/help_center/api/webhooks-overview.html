Webhooks overview

Last updated: 2026-06-15

Applies to: InvoicePilot 2.3.0+

Available on: Professional, Enterprise

Webhooks send an HTTPS POST to your endpoint when something happens in InvoicePilot, so you do not have to poll the API.

PlanWebhook endpoints
StarterNot available
Professional5
Enterprise25

Set up an endpoint

  1. Go to Settings > Developer > Webhooks, or call POST /v2/webhook_endpoints.
  2. Enter an HTTPS URL. Plain HTTP URLs are rejected with IP-4226.
  3. Choose the events to subscribe to.
  4. Copy the signing secret. It starts with whsec_ and is shown once.

Webhooks became generally available on 2026-06-15 for API v2.
