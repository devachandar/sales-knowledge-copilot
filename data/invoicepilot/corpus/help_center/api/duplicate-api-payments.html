Troubleshooting: duplicate payments from API retries

Last updated: 2026-05-12

Applies to: InvoicePilot 2.2.1

Available on: Starter, Professional, Enterprise

Retries of POST /v2/payments with the same Idempotency-Key created duplicate payments. Other endpoints were not affected.

This is BUG-2210-02 (High). It affected 2.2.1. It was fixed in 2.3.0.

What to do

  • On 2.2.1, check GET /v2/payments for an existing payment before retrying.
  • Delete duplicates with DELETE /v2/payments/{payment_id}; the invoice reopens.
  • Fixed in 2.3.0. Idempotency-Key now works on every POST endpoint.
