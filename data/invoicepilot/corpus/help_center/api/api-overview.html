API overview: v1 and v2

Last updated: 2026-01-20

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

InvoicePilot has two REST APIs.

API v1API v2
StatusLegacy (still available)Current
Base URLhttps://api.invoicepilot.example/v1https://api.invoicepilot.example/v2
Paginationpage and per_pageCursor-based
Introduced2.0.02.2.0

New integrations should use v2. Existing v1 integrations keep working and do not need to migrate right away.
