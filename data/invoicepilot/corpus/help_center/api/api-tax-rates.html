Tax rates endpoint

Last updated: 2026-04-02

Applies to: InvoicePilot 2.2.0+

Available on: Starter, Professional, Enterprise

Added to API v2 on 2026-04-02. See the API changelog.

MethodPathDoes
GET/v2/tax_ratesList tax rates, including archived ones with archived=true
POST/v2/tax_ratesCreate a tax rate
POST/v2/tax_rates/{tax_rate_id}/archiveArchive a tax rate. Existing invoices keep it
