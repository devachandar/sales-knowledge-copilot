Security overview

Last updated: 2026-04-15

Available on: Starter, Professional, Enterprise

InvoicePilot encrypts data in transit with TLS 1.2 or later and at rest with AES-256.

  • Two-step verification for every user
  • SOC 2 Type II report available on request
  • Data hosted in the US and the EU
  • Audit log on Enterprise (13 months)

Single sign-on (SAML) is not available today.
