Search invoices

Last updated: 2025-06-15

Applies to: InvoicePilot 2.0.0+

Available on: Starter, Professional, Enterprise

Use the search bar on the Invoices list. Since 2.0.0, search covers line-item descriptions as well as invoice numbers.

  • Search by invoice number: INV-000123
  • Search by customer name
  • Search by any word in a line-item description
  • Filter by status: Draft, Sent, Overdue, Paid, Void
