Troubleshooting: clients got the same reminder twice

Last updated: 2025-11-04

Applies to: InvoicePilot 2.1.0

Available on: Starter, Professional, Enterprise

Client-level reminders with a send window that crossed midnight UTC were sent twice.

This is BUG-2100-04 (Medium). It affected 2.1.0. It was fixed in 2.1.1.

What to do

  • Update to 2.1.1; this happens automatically.
  • On 2.1.0, set the reminder send window so it does not cross midnight UTC.
